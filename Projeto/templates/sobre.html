Sobre o IncluiVagas

O IncluiVagas é uma plataforma criada para ajudar pessoas com deficiência a encontrarem oportunidades de emprego de forma mais fácil.

A ideia do projeto é aproximar empresas que oferecem vagas inclusivas de candidatos que procuram uma oportunidade no mercado de trabalho.

O sistema permite cadastrar, visualizar, editar e excluir vagas, facilitando a divulgação de oportunidades para diferentes perfis de candidatos.

Objetivo

Incentivar a inclusão no mercado de trabalho e tornar a busca por vagas mais acessível para todos.

Tecnologias utilizadas

  • Python
  • Flask
  • HTML
  • CSS
  • JavaScript
  • Bootstrap
  • JSON
